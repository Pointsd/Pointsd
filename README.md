I don't just write features — I **architect and own entire systems** end to end: product, data model, backend, frontend, security, and deployment. The kind of software that runs in production under real load, with real users and real money moving through it. Everything under the **NXA** brand is my own company and my own work.

- **Business platforms** — ERP / POS / CRM, inventory &amp; FIFO costing, production, payments, offline-first
- **Web &amp; PWA** — multilingual & government platforms, dashboards, interactive 3D / map UIs

- **DevOps** — Docker, CI/CD (GitHub Actions), Nginx, Linux/VPS, cross-platform native builds (Win/macOS/Linux)
- **Quality** — test-driven (**368+ tests**), schema migrations, reproducible environments, zero-downtime cutovers
